# Week 02: Data Structures & Complexity Quiz (Part B)

### Q1. What is the time complexity for accessing an element at a known index in a 1D array?
- **Answer:** **B. O(1)**
- **Explanation:** Array memory is contiguous, enabling instant direct address calculation.

### Q2. The operation of adding a new element to a data structure is known as what?
- **Answer:** **C. Insertion**

### Q3. When choosing an appropriate data structure for a given problem, what is the most crucial step?
- **Answer:** **C. Matching the required operations and constraints to the strengths of different data structures**

### Q4. Storing frequently accessed calculations in a cache illustrates what concept?
- **Answer:** **C. Time vs space trade-offs**

### Q5. Two sequential non-nested loops with bounds m and n have what overall time complexity?
- **Answer:** **B. O(m + n)**

### Q6. In which data structure are elements arranged sequentially with one predecessor and successor?
- **Answer:** **C. Linear data structure**

### Q7. Simplified Big-O complexity for 2n + 5 operations:
- **Answer:** **C. O(n)**
- **Explanation:** Drop constant coefficients and lower-order terms.

### Q8. Which is an example of a non-primitive data structure?
- **Answer:** **D. Linked list**

### Q9. Time complexity of visiting every element in an m x n 2D array:
- **Answer:** **B. O(m × n)**

### Q10. What is the fundamental purpose of a data structure?
- **Answer:** **C. To organize, store, and access data efficiently for specific operations**
