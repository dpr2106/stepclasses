# STEP SEM-3 · CodInClub | BridgeLabz

Repository containing assignments, practice problems, quizzes, and concept questions for the 10-week STEP program.

## Repository Structure

Each week is organized on its dedicated branch (week-01 to week-10) with two main subfolders:
- practice/: Practice coding problems, concept questions, and quiz answers.
- ssignment/: Core weekly coding assignments and problem implementations.

### Weekly Curriculum Overview

| Week | Branch | Topic / Focus |
|---|---|---|
| Week 1 | week-01 | Object-Oriented Programming (Inheritance, Polymorphism, Abstract Classes, Interfaces) |
| Week 2 | week-02 | Arrays, Searching, Two Pointers & Sliding Window |
| Week 3 | week-03 | Linked Lists (Singly Linked List, In-Place Reversal, Node Operations) |
| Week 4 | week-04 | Stacks & Queues (LIFO/FIFO, Circular Queues, Applications) |
| Week 5 | week-05 | Recursion & Backtracking |
| Week 6 | week-06 | Sorting Algorithms & Divide and Conquer |
| Week 7 | week-07 | Trees & Binary Search Trees (BST) |
| Week 8 | week-08 | Heaps & Priority Queues |
| Week 9 | week-09 | Hashing & Hash Tables |
| Week 10 | week-10 | Graph Algorithms & Dynamic Programming Fundamentals |
